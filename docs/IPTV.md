# M3U / IPTVの接続先をコピー

1. TV側を[TCLTV-Bondriver 0.6.0](https://github.com/Long0823-1/TCLTV-Bondriver/releases/tag/v0.6.0)へ更新・セットアップ・再起動し、通信維持を有効にします。
2. スマホ版0.4.1を上書きインストールします。既存設定を使って視聴できますが、IPTV情報を取得するにはTVの確認コードでもう一度接続情報を取得してください。
3. 「設定」で使用するチューナーとIPを保存します。
4. 「IPTVのM3U接続先」を開き、「URLをコピー」を押します。
5. VLCなど、HTTP MPEG-TSとMPEG-2/AACに対応するアプリへM3U URLを登録します。

![IPTV接続先](images/mobile-iptv-v0.4.0.png)

画像はAndroid 11エミュレーター上のテスト用IP・ダミーキーです。放送局ロゴ・放送映像・実際の接続キーは含みません。

URLにはIPTV専用キーが入ります。従来のBonDriver認証キーは含めませんが、取得したURLやM3Uを公開しないでください。TVと通信できる家庭内LAN向けです。

各チューナーでIPTVは1セッションずつです。BonDriver・このアプリ・外部IPTVアプリを同時使用する場合は、異なるチューナーを指定してください。画質変換はありません。TV側0.6.0以降はXMLTV番組表を配信できます。このアプリ内の既存の番組表取得と再生はそのまま利用できます。

「TV側の通信維持設定」は取得時の情報です。TV側で変更した場合は情報を再取得してください。IPが変わった場合は新しいIPを保存してからURLをコピーします。
## 番組表XMLをコピー（0.4.1）

1. TV APKを0.6.0、スマホを0.4.1へ上書きします。今回のTV更新ではセットアップとTV再起動も実行します。
2. TVの確認コードで接続情報を再取得します。
3. TV側が空きチューナーで自動収集します。外部から視聴すると収集を中断し、視聴終了後に再開します。
4. スマホの「設定」→「IPTVのM3U接続先」→「番組表XMLをコピー」で、IPTVアプリのEPG/XMLTV URL欄へ貼り付けます。M3Uからの自動認識にも対応します。

XMLの取得だけで選局はしません。初回収集前や未受信局には番組がない場合があります。視聴を停止する必要はありません。[TV側の詳しい説明](https://github.com/Long0823-1/TCLTV-Bondriver/blob/main/docs/XMLTV.md)を参照してください。

![XMLTV URLのコピー](images/mobile-xmltv-v0.4.1.png)

画像のIP・キーはダミーです。
