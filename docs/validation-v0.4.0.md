# 0.4.0 検証記録（2026-10-26）

Android 11 / API 30 x86_64エミュレーターと実機TCL TV 0.5.0で検証しました。配布APKはARM64、署名検証済みです。Xiaomi 12T Proは0.2.0で映像表示の改善を利用者が確認しています。0.4.0の実スマホ試験は未実施です。

- 実TVの確認コードから37サービスを取得。IPTV専用接続情報あり、通信維持設定あり、従来の認証キーがIPTV URLに含まれないことを確認。
- M3U設定画面とURLコピーの自動操作試験が通過。公開画像にはTEST-NETのIPとダミーキーを使用。
- 旧INIの読み込み、新設定の保存・再読込、不正ポートの拒否をJavaで検証。
- 実放送の30秒再生: 映像デコード1,608、表示803、音声デコード2,665、EIT 417（CRCエラー0）、番組134件。再生中かつ最後の5秒でも155フレーム増加を確認。
- エミュレーターにはMPEG-2 MediaCodecがないためVLCソフトウェアフォールバックで検証。MediaCodec優先設定は維持しています。

内部中継は短い上流切断を最大45秒まで再試行します。待機中のnull TSは接続を維持するためのもので、映像・音声の停止をなくすものではありません。混雑時は古いTSをパケット境界で破棄し、ライブ再生を優先します。

TV側の実リモコン消灯・2系統受信・電源設定復元の結果は[TV側検証記録](https://github.com/Long0823-1/TCLTV-Bondriver/blob/main/validation/v0.5.0.md)を参照してください。全画面・UIの既存検証は[0.3.0](validation-v0.3.0.md)にあります。

追加確認: TVの画面OFF・Asleep（sleep_button）を確認して30秒再生。映像1,618・表示811・音声2,675、最後の5秒で152フレーム増加、EIT 414・CRCエラー0。再生中を維持し、上流再接続0回でした。
