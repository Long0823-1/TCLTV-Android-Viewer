# 0.3.0 検証結果

## 確認した範囲

Android 11 / API 30 x86_64エミュレーター、1080×2340、3ボタンナビゲーションで実行しました。TVや利用中のチューナーを選局せず、自作のMPEG-2映像・AAC音声のTSをアプリ内から再生しました。

- ライト：描画356フレーム、全画面2340×1080、プレーヤー位置0,0・画面全体との一致を確認。
- ダーク：描画365フレーム、同じ全画面・操作の試験を通過。
- ステータスバー／ナビゲーションバー非表示、操作パネル3秒で非表示・タップで再表示を確認。
- 比率維持から画面を埋める拡大への切り替え、通常画面のヘッダー／下部ナビゲーションへの復帰を確認。
- 外部ロゴ11種類のうち10種類を取得・キャッシュ。フジテレビはこのAndroid 11イメージの証明書検証で取得できず、局名表示へフォールバック。証明書検証は無効化していません。
- 初回IPの編集とINIなしでのIP保存をSettingsTestで確認。
- ARM64配布APKのv2/v3署名、APK内に局ロゴ画像がないことを確認。

テストコードは `mobile/tests/android/FullscreenTest.java` と `SettingsTest.java`。公開スクリーンショットでは撮影直前にロゴ表示を汎用のTV表示へ置き換えています。この処理はデバッグ用テストだけに含まれ、配布APKには入りません。テスト映像や実際の放送TSは配布しません。

## 実機確認と制限

0.2.0でXiaomi 12T Proに映像が表示されたことは利用者が確認済みです。0.3.0の新UI、Xiaomi実機のジェスチャーナビゲーションや画面切り欠き、Android 12以降のシステムアクセント色は実機では未検証です。今回の変更でTV側の配信・復号処理は変更していません。

局ロゴは外部取得と端末キャッシュ方式です。APK・Git・配布ZIPへ画像を同梱しません。サイト変更・ネットワーク・証明書の条件によって取得できない局は短縮局名で表示します。
