# 局ロゴ

放送局のロゴ画像はAPK・ソースコード・配布ZIPへ同梱しません。対応する画像のURLと出典のみ `mobile/assets/station_logos.json` に記載し、表示時に外部から取得して端末内へキャッシュします。放送TSからロゴを取得する機能ではありません。

局一覧はTVのスキャン結果から読み込みます。局名からロゴを選び、臨時サービスなどでは同じ放送波の局名を参照します。未登録局・外部取得失敗時は局名の短縮表示になります。取得済みの画像はオフラインでも利用できます。設定の「局ロゴを再読み込み」でキャッシュを消して再取得できます。

対応する出典：NHK総合・Eテレ（Wikimedia Commons）、日テレ、TBS、テレビ朝日、テレビ東京、フジテレビ、TOKYO MX、J:COM、チバテレ、テレ玉（各局公式サイト）。画像URLの変更や接続条件によって取得できない場合があります。

ロゴ・商標の権利は各放送局に帰属します。アプリのMITライセンスには含まれません。外部取得方式も画像の利用条件の確認を不要にするものではありません。各局による公式アプリ・公認を示すものではありません。
