# 動作検証（2026-10-25）

Androidスマートフォン向けアプリ0.1.0の開発検証です。Xiaomi 12T Pro実機では未確認です。

## PC上の解析テスト

- スキャン由来の37サービス設定を読み込み・書き戻し。
- 不正な接続キーを拒否。
- ARIB日本語・番組記号の基本デコード。
- 実際のTSからEIT 156セクション、CRC異常0、番組106件。
